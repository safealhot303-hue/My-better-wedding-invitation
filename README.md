# خالد وندى — دعوة خطوبة White & Gold

## النسخة الحالية
- ألوان عاجي/أبيض + ذهبي مع أخضر داكن وBurgundy كألوان مساعدة من الصورة.
- Hero عريض متوافق مع سطح المكتب والموبايل.
- زر «تأكيد الحضور» أسفل صورة الدعوة ينقل إلى نموذج RSVP.
- RSVP يرسل البيانات إلى البريد: Safe.alhot303@gmail.com عبر FormSubmit.
- عد تنازلي.
- Google Maps وGoogle Calendar.
- موسيقى مع زر تشغيل/كتم. إذا منع المتصفح التشغيل التلقائي بالصوت، تبدأ الموسيقى عند أول تفاعل من الزائر.
- أنيميشن ظهور سلس عند النزول في الصفحة، مع تأخير بسيط للعناصر المتتالية، وحركة دخول للـHero والزر، وحركات hover خفيفة.

## ملاحظة RSVP
FormSubmit خدمة خارجية. عند أول إرسال قد تصل رسالة تحقق إلى بريد الاستقبال؛ يجب تأكيد البريد حتى يبدأ استقبال النماذج.
