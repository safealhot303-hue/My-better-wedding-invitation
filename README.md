# دعوة خالد وندى — أخضر وذهبي

هذه نسخة أولية قابلة للنشر على GitHub Pages، مبنية كتطبيق ويب مستقل باستخدام HTML/CSS/JavaScript.

## أهم الملفات
- `index.html` محتوى الدعوة
- `style.css` التصميم والألوان والحركات الأساسية
- `script.js` العد التنازلي والتقويم وRSVP
- `assets/hero.jpg` صورة الغلاف التي تم توفيرها في المحادثة

## قبل النشر
في `script.js` غيّر:
1. `EVENT_DATE` إلى التاريخ والساعة الفعلية.
2. `whatsappNumber` إلى رقم استقبال التأكيد بصيغة دولية بدون +.

في `index.html` يمكنك تغيير الأسماء والنصوص والبريد.

## نشر سريع على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` ومجلد `assets`.
3. من Settings > Pages اختر النشر من الفرع `main` والمجلد `/root`.
4. انتظر حتى يظهر رابط GitHub Pages.

## ملاحظة
رابط الخريطة يستخدم بحث Google Maps عن "نادي اليخت ببورفؤاد". يفضّل لاحقًا استبداله بالرابط المباشر للموقع الذي تختاره أنت من Google Maps.
